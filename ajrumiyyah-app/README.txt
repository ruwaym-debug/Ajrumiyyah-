Al-Ajurrumiyyah study app (installable)
1. Upload ALL files in this folder to any https website (GitHub Pages, Netlify, Cloudflare Pages all free).
2. Open the site on your phone.
   iPhone: Safari > Share > Add to Home Screen.
   Android: Chrome > menu > Install app (or Add to Home screen).
It then opens full screen like an app and works offline after the first visit.
Note: install and offline mode do not work from a file opened on the phone; they need https hosting.
Recitation needs microphone permission and internet.

This build (latest): completely redesigned interface (new look, new layout, new icons). Rosette section marker,
ruled manuscript page for the matn, margin-note layout on wider screens, a sections sidebar on desktop, a floating
bottom bar on phones, 40-segment progress tracker, previous/next buttons at the end of each section.
All 40 sections, diagrams, 3-level examples, memorize modes and recitation are unchanged.
